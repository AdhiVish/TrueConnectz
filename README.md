# True Connectz HR Services

Website for True Connectz HR Services, built with React, TypeScript, Vite, Tailwind CSS v4, motion and Lenis.
Based on the client's pitch page and the "Website Upgrade Guidance" document; colours are taken from the logo.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

- All copy (services, enquiry form fields, industries, steps, proof placeholders) lives in `src/data/site.ts`.
- Logos and favicon are in `public/brand/` (cropped, web-sized versions of the supplied 6000px PNGs).
- Proof figures, testimonials, the Managing Director profile, mission and vision are placeholders until the client confirms them.
